# Louis DeMaso — Sales Resume

A responsive, single-page sales resume. Built with semantic HTML, CSS, and vanilla JavaScript, with a Loom introduction and accessible reduced-motion support.

## Hosting

Publish the repository root from `main` through GitHub Pages. No build step or dependencies are required.

## Content

Experience is based on the October 22, 2026 high-ticket sales resume. Career totals are self-reported. The PDF is not linked or bundled.
